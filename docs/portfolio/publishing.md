# 포트폴리오 공개 방식

## 기준 산출물

상호작용의 기준본은 Streamlit 대시보드다. 직업 선택, 총량·게시물당 지표 비교,
댓글·추천·조회 정렬과 원문 이동은 웹 링크에서 제공한다. 공개할 때에는 검증된 ZIP을
서버 비공개 저장소에 두고 `MAPLE_EXPORT_PATH`만 배포 환경 변수로 설정한다.

## PPT/PDF 동반 자료

PPT/PDF는 문제 정의, 데이터 신뢰성, 핵심 발견, AI 실험 설계, 한계를 설명하는 정적
스토리 문서로 만든다. 정적 문서 자체가 상호작용한다고 표현하지 않고, 표지와 각 핵심
차트에 웹 대시보드 링크 및 QR 코드를 넣어 기준본으로 돌아오게 한다.

대시보드와 정적 자료의 수치가 달라지지 않도록
`maple_monitor.dashboard.export_presentation.portfolio_snapshot`의 JSON 직렬화 가능한
계약을 공통 입력으로 사용한다. 이 계약에는 출처·체크섬·전체 반응 지표·직업별 총량과
게시물당 지표·분석 진행 상태가 포함된다.

## 공개 전 점검

1. ZIP 체크섬과 최신 관측 시각을 확인한다.
2. 본문·댓글이 없는 단계에서는 감성 결과를 노출하지 않는다.
3. 메이플스토리 공식 이미지 출처와 공개 범위를 다시 확인한다.
4. 데스크톱과 모바일에서 표, 툴팁, 원문 링크를 점검한다.
5. PPT/PDF에 기록한 수치와 배포된 스냅숏의 생성 시점을 함께 표기한다.
