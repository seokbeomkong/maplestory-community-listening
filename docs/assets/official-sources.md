# 공식 비주얼 출처

대시보드에는 넥슨이 공개한 메이플스토리 공식 이미지 외의 캐릭터·게임 이미지를
사용하지 않는다.

- 캠페인: [서약의 지배자, 레테](https://maplestory.nexon.com/promotion/event/2026/20260618/event01)
- 사용 이미지: [공식 프로모션 배경](https://lwi.nexon.com/maplestory/2026/0618_lethe_A0ECF482FBC7C753/bg1_413b4f4fbeab575f.jpg)
- 제공자: NEXON Korea / MapleStory
- 사용 위치: 포트폴리오 첫 화면의 키 비주얼

외부 이미지가 로드되지 않아도 데이터와 탐색 기능은 그대로 동작한다. 공개 배포 전에는
넥슨 브랜드 가이드와 채용 포트폴리오 제출 범위를 다시 확인한다.
