# 의미 분석 표본 확대와 가독성 개선 설계

## 목표

직업 게시판 의미 분석을 선택한 직업 카테고리에 엄격히 한정하고, 1–3건에 머물던
표본을 해석 가능한 수준으로 늘린다. 축과 라벨이 충돌하는 차트는 정확한 건수와 비율이
먼저 읽히는 분포 카드로 교체한다. 주제·의도·작성 글 감성·댓글 반응의 분류 기준과
게시물별 근거를 대시보드 안에서 설명한다.

## 선택한 접근

전수 상세 수집은 원문 서버 부하와 갱신 시간을 크게 늘린다. 제목만 이용한 전수 분류는
본문·댓글 기반 결과와 품질 기준이 달라진다. 따라서 상세 근거를 유지하는 상위 반응 표본
확대를 사용한다.

- 최근 90일 안에서 댓글·추천·조회 순위를 각각 계산한다.
- 직업 분석 단위는 지표별 5건, 자유·질문·팁 게시판은 지표별 20건을 선택한다.
- 동일 게시물은 한 번만 분석한다.
- 직업 화면은 `analysis_unit`이 선택 직업과 같은 행만 사용하며 게시판 ID와 직업
  카테고리 범위를 함께 표시한다.
- 선택 정책 버전을 manifest에 기록한다. 동일 ZIP과 동일 정책은 재실행하지 않고,
  정책이 확대되면 기존 분석 행을 재사용한 뒤 새 후보만 상세 수집한다.

현재 Export Release에서는 후보가 114건에서 약 573건으로 증가하며, 직업별 중앙값은
약 10건이다. 원문 수가 적거나 세 지표 상위 글이 겹치면 이보다 적을 수 있다.

## 화면 구성

의미 분석 상단에 분석 범위, 표본 선택 기준, 실제 분석 게시물·댓글 수와 기간을 표시한다.
이어 다음 네 분포를 2×2 카드로 배치한다.

1. 주요 주제
2. 작성 의도
3. 작성 글 감성
4. 댓글 반응

각 항목은 범주명, `n건`, 전체 대비 비율, 비율 막대를 함께 보여준다. 표본이 5건
미만이면 비율 일반화에 주의하라는 문구를 표시한다. 축·눈금·세로축 제목은 사용하지
않는다.

## 분류 기준 설명

접을 수 있는 `분류 기준과 해석 방법` 영역에서 다음을 명시한다.

- 주제: 제목·본문에서 주제별 사전 표현의 출현 수를 비교한다.
- 의도: 요청·불만·토론·질문·칭찬·정보 표현의 출현 수를 비교한다.
- 작성 글 감성: 본문의 긍정·부정 표현을 독립적으로 탐지하고 모두 있으면 혼합으로
  분류한다.
- 댓글 반응: 댓글별 감성을 먼저 분류한 뒤 중립을 제외한 최빈 범주를 사용하고 동률이면
  혼합으로 분류한다.
- 반응 지표는 표본 선택에만 사용하며 감성 라벨에는 사용하지 않는다.

기준표에는 실제 버전형 키워드 사전의 대표 표현과 동률·무근거 기본값을 표시한다.
근거 게시물 표에는 선택 사유, 감성 근거 표현과 원문 링크를 유지한다.

## 오류 처리와 재현성

상세 수집 실패는 해당 게시물만 제외하고 manifest에 실패 수를 기록한다. 완성된 CSV와
manifest는 원자적으로 교체한다. 분석 결과는 ZIP SHA-256, 모델 버전, 선택 정책 버전에
묶는다. 새 정책 실행 도중에는 이전 완성본을 계속 읽는다.

## 검증

- 후보 선택이 직업별로 격리되고 직업·일반 게시판별 상한을 적용하는지 단위 테스트한다.
- 정책 변경 시 기존 분석 행을 재사용하고 새 후보만 가져오는지 테스트한다.
- 분포 집계가 건수와 비율을 정확히 계산하는지 테스트한다.
- 직업 화면에 선택 직업 범위와 네 분포, 분류 기준 설명이 표시되는지 AppTest로 검증한다.
- 실제 Export Release로 후보 수, 직업별 게시판·카테고리 격리, 브라우저 가독성을 확인한다.
